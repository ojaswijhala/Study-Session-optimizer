# Project Statement

## Problem Statement
Students often have several subjects and topics with different difficulty levels, deadlines, and estimated study times. The Study Session Optimizer helps organize these topics, calculate their priority, suggest a study order, track completion, search topics, and show overall progress.

## Scope
The project includes topic entry, validation, rule-based priority calculation, study-order generation, completion tracking, search, progress summary, and console interaction.

The current version does not include machine learning, automatic timetable generation, external calendar integration, accounts, database/cloud storage, or a graphical interface.

## Target Users
Students who want a simple console-based way to organize study topics according to urgency, difficulty, and estimated study time.

## High-Level Features
1. Add and validate study topics.
2. Calculate a priority score.
3. Suggest a study order for pending topics.
4. Mark topics as completed.
5. Search topics or subjects.
6. Display completion progress.
